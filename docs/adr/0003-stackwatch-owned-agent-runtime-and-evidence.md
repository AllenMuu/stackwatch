# Keep investigation control and evidence governance in StackWatch

Each Deep Investigation step is driven by a structured Agent Decision but validated, bounded, and persisted by StackWatch rather than an Agent Framework. Tool failures become persisted Observations and missing evidence, not fabricated Evidence; only redacted summaries, provenance, time range, and content hashes are retained. Local versioned Incident Fixtures are the primary evaluation mechanism, keeping quality checks deterministic and independent of live providers.
